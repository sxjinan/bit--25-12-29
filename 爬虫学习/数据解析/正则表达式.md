在这部分，我们将用简单示例，快速上手正则表达式（Regular Expression，简称 regex）。

## 1. 正则表达式能做什么？

- 在一段文本里 **查找** 想要的内容（比如所有手机号、邮箱）
- 从一大段 HTML/日志中 **提取** 关键信息
- 对字符串做 **校验**（比如账号格式是否正确）

正则表达式本质上就是：**用一小段“规则字符串”去匹配另一段文本。**

## 2. 基本匹配：普通字符

大部分字符本身就表示它自己：

- `a` 匹配文本中的字母 a
- `abc` 匹配连续出现的 abc

示例：

- 正则：`hello`
- 文本：`hello world`  → 可以匹配到 hello

## 3. 常见元字符（有特殊意义的符号）

这些符号在正则中不是字面意思，而是“规则”。

- `.`  ：匹配除换行外的 **任意一个字符**
- `\d` ：匹配一个数字 digit（0–9）
- `\w` ：匹配一个“单词字符”（字母/数字/下划线）
- `\s` ：匹配空白（空格、制表符、换行等）
- `^`  ：匹配字符串 **开头**
- `$`  ：匹配字符串 **结尾**

示例：

- 正则：`^hello`  → 匹配“以 hello 开头”的字符串
- 正则：`\d\d\d` → 任意连续 3 个数字，比如 123、007

## 4. 量词：重复多少次

用来描述“前面的内容重复几次”。常见量词：

- `*` ：重复 0 次或多次（可以没有，也可以很多）
- `+` ：重复 1 次或多次（至少出现 1 次）
- `?` ：重复 0 次或 1 次（要么没有，要么一个）
- `{n}` ：重复 **恰好 n 次**
- `{n,}`：重复 **至少 n 次**
- `{n,m}`：重复 **n 到 m 次（含边界）**

示例：

- `a+` ：一个或多个 a，例如 `a`、`aa`、`aaaa`
- `\d{3}` ：连续 3 个数字，例如 123、007
- `\d{11}` ：常用来匹配 11 位手机号码（还需结合开头约束）

## 5. 字符集：在几种字符里选一个

用中括号 `[]` 表示一个“字符集合”，里面的任意一个都可以匹配：

- `[abc]` ：匹配 a 或 b 或 c 中的任意一个字符
- `[0-9]`：匹配任意一位数字
- `[A-Za-z]`：匹配任意英文字母

示例：

- 正则：`gr[ae]y` → 可以匹配 `gray` 或 `grey`

如果在中括号里第一个位置写 `^`，表示“取反”：

- `[^0-9]`：匹配 **不是数字** 的任意一个字符

## 6. 分组与或：() 和 |

- `()` ：把一部分正则“括起来”当一个整体（也可以在之后提取这一部分）
- `|`  ：表示“或者”，在多个模式中选一个

示例：

- `(cat|dog)` ：匹配 `cat` 或 `dog`
- `ab(c|d)e` ：可以匹配 `abce` 或 `abde`

## 7. 常见实战例子

### 7.1 匹配简单邮箱

> 注意：这里只是演示，不是严谨的所有邮箱规则。

正则：`[\w.-]+@[\w.-]+\.\w+`

- `[\w.-]+` ：用户名部分，字母/数字/下划线/点/减号，出现 1 次或多次
- `@` ：固定的 @ 符号
- `[\w.-]+` ：域名部分
- `\.\w+` ：点 + 至少一个字母，比如 .com、.cn

### 7.2 匹配 11 位手机号码（简单版本）

正则：`^1\d{10}$`

- `^1` ：以数字 1 开头
- `\d{10}` ：后面跟着 10 个数字
- `$` ：到此结束，不再多出其他字符

## 8. 在 Python 中使用正则

Python 提供了内置模块 `re`，常用几个函数：

- `re.search(pattern, string)`：在整段字符串中查找 **第一个** 匹配
- `re.findall(pattern, string)`：返回 **所有** 匹配结果（列表）
- `re.sub(pattern, repl, string)`：把匹配到的内容替换为 `repl`

示例：从字符串中提取所有数字：

```python
import re

text = "今天看了 3 部电影，评分 9.5 和 8.8 还有 7"
numbers = re.findall(r"\d+\.\d+|\d+", text)
print(numbers)  # ['3', '9.5', '8.8', '7']
```

## 9. 初学者常见坑

1. **忘记转义反斜杠**：在 Python 字符串里写正则时，`\d` 实际要写成 `"\\d"`，或者前面加 `r` 写成原始字符串：`r"\d"`（推荐）。
2. **用 `.` 过于贪婪**：`.*` 会尽可能多地匹配，容易“吃掉”本不想包含的内容，可以用 `.*?`（非贪婪）在部分场景下控制范围。
3. **直接用正则解析复杂 HTML**：对简单页面可以，对很复杂的结构建议配合 HTML 解析库（如 BeautifulSoup、lxml）。
